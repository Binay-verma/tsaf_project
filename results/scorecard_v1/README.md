# Registered-test scorecard (descriptive additions)

scorecard.csv: every registered typed-vs-pooled hypothesis with its registered decision and a 95% t interval over its units (descriptive, unadjusted; the registered tests are the sign-flip tests). forest_by_state.csv: per-state lead-1 typed minus pooled MASE with 95% t intervals over family-years, 14 new states. mixed_model.csv: linear mixed model diff ~ 1 with crossed random effects for state and family-year (REML), both tests pooled; converged flag reported. Written after both registered analyses; exploratory.
