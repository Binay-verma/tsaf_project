# 2026 calendar evidence location and rolling-activation assessment (v2)

Read `record.json`. This record locates likely copies of the 2026 Delhi, Karnataka and Maharashtra notifications on **secondary hosts**. It records machine-extracted family entries as leads for human verification only; no date is a verified feature date. v1 (`review/india2026_calendar_feasibility_v1`) is unchanged.

Key consequence: the rolling study's registered activation rule needs a complete primary 2024–2027 package. 2027 state lists are unlikely before December 2026, so under the registered rule the 16 November window and following windows would be recorded misses. Changing that rule is an author decision (record.json, options A/B).
